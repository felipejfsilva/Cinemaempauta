# Fontes

Para uso offline, baixar de https://fonts.google.com:

- **Playfair Display** (Regular 400, Bold 700, Italic 400)
- **Barlow Condensed** (Regular 400, SemiBold 600)

Converter para .woff2 e colocar aqui. Descomentar os @font-face em `base.css`.

Por padrao, os templates usam Google Fonts via @import (requer internet).
